# Hackathon brief: Chore Roulette

**Theme:** Student Life Hacks
**Time limit:** 60 minutes (the workshop) / 24 hours (a real hackathon)

## Problem
Flatmates argue about who takes the bins out. Chores get dumped on the same person,
and nobody remembers who did what last week.

Build a web app that assigns chores fairly **and makes it fun**.

## Must have (MVP)
1. Add flatmates and chores.
2. Spin a wheel to assign each chore, weighted so nobody gets the same chore twice in a row.
3. Save the rota so it survives a page refresh.

## Stretch goals
- A "chore streak" leaderboard
- A "copy to group chat" button that copies the week's rota as text
- Dark mode
