# Judging playbook

## Hook formulas (pick one)
- **The moment:** "It's 11pm. The bins are overflowing. Again. And everyone swears it's not their turn."
- **The number:** "The average flat has <n> chore arguments a month." Only use a number you can back up. Otherwise, use the moment.
- **The question:** "Hands up if you've ever done a chore that wasn't yours." (This works in a room, so pause for it.)

## Tailoring for sponsors
- Name the sponsor's prize out loud, and show the exact part of the project that targets it.
- For a "Best use of <tool>" prize, show the workflow, not just the result (for example, flash the CLAUDE.md or a skill).
- Don't claim prizes you haven't built for. Judges notice.

## Demo rules
- Demo first, slides second. A working demo is worth more than any slide.
- Use pre-filled data. Never type long text live.
- Know what you'll do if it breaks: have a backup video or screenshots ready.
- Narrate what the judge should notice ("watch: it skips Sam, because Sam did the bins last week").

## Closing lines that land
- Echo the hook: "So tonight, nobody argues about the bins. The wheel decides."
- One clear ask: "Try it now, at <link>."
