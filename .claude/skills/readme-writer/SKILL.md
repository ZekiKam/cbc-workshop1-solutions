# README writer

1. Read `PLAN.md`, `BRIEF.md` and `app/index.html`.
2. Write `README.md` using the structure in [template.md](template.md).
3. Only describe features that exist in the code. Never invent any.
4. Keep it under 300 words. Judges skim.
